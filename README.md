# 🪙 MetalPulse - 실시간 금속 시세 모니터링 웹 대시보드

MetalpriceAPI를 활용하여 **금(Gold), 은(Silver), 구리(Copper), 플래티넘(Platinum)** 등 주요 귀금속 및 산업용 금속의 실시간 시세와 기간별 변동 추세를 한눈에 조회하는 단일 페이지(SPA) 웹 애플리케이션입니다.

---

## 📌 1. 프로젝트 개요 (Project Overview)

- **서비스명**: MetalPulse (메탈펄스)
- **개발 목적**: 글로벌 외환 및 원자재 시장에서 거래되는 대표 금속들의 현재 시세 및 기간별 추세를 직관적인 카드뷰와 독립된 세로형 차트를 통해 제공
- **핵심 특징**:
  - **단일 페이지(SPA)** 기반의 직관적이고 몰입감 높은 옵시디언 다크 테마 UI
  - 상단 레이아웃: 금, 은, 구리, 플래티넘 등 주요 금속의 **실시간 카드뷰** (현재가, 24h 변동률, 고저 범위 게이지, 미니 스파크라인)
  - 하단 레이아웃: 기간 선택(7D, 1M, 3M, 6M, 1Y, 직접 지정)에 따른 **금속별 세로형 1:1 독립 차트뷰**
  - **OpenAPI**: [MetalpriceAPI](https://metalpriceapi.com) 규격 완벽 대응 (`/latest`, `/timeframe`)
  - **스마트 Fallback 엔진 탑재**: API 키가 없거나 무료 티어 한도 초과 시에도 실제 2026년 시세 기반 고정밀 시뮬레이션 데이터를 자동 생성하여 즉시 구동 가능
  - **다중 통화 & 단위 환산**: USD($), KRW(₩), EUR(€), JPY(¥) 및 트로이온스(oz), 그램(g), 킬로그램(kg) 실시간 연동

## 📋 2. 기능 명세서 (Functional Specification)

### 2.1 상단 네비게이션 & 글로벌 컨트롤
| 기능 ID | 기능명 | 상세 내용 |
| :--- | :--- | :--- |
| **F-01** | 브랜드 & 상태 표시 | MetalPulse 타이틀, 실시간 API 연결/데모 모드 상태 배지 표시 |
| **F-02** | 기준 통화 선택 | KRW(원화), USD(달러), EUR(유로), JPY(엔) 선택 시 실시간 환율 적용 및 전 화면 재계산 |
| **F-03** | 중량 단위 선택 | Troy Ounce(oz), Gram(g), Kilogram(kg) 지원 (1 oz = 31.1035g 기준 계산) |
| **F-04** | API Key 설정 모달 | 사용자가 발급받은 MetalpriceAPI Key 입력, 로컬스토리지 저장, 데모 모드 토글 |
| **F-05** | 수동 새로고침 | 데이터 즉시 갱신 및 마지막 조회 시각 타임스탬프 업데이트 |

### 2.2 상단 레이아웃: 금속별 실시간 시세 카드뷰 (Top Layout)
- **표시 대상**: 금(XAU), 은(XAG), 구리(XCU), 플래티넘(XPT)
- **카드 구성 요소**:
  1. 금속 고유 심볼 및 한글/영문 명칭, 메탈릭 아이콘
  2. 선택 통화/단위가 반영된 실시간 가격 (대형 볼드 폰트)
  3. 전일 대비 변동폭 및 등락률(%) 뱃지 (상승: 그린/상승삼각, 하락: 레드/하락삼각)
  4. 24시간 최고가(High) / 최저가(Low) 및 실시간 위치 게이지 바
  5. 24시간 미세 흐름을 나타내는 미니 캔버스 스파크라인(Sparkline)
  6. 금속 테마 컬러 앰비언트 글로우 및 3D 호버 인터랙션

### 2.3 중간 레이아웃: 기간 선택 컨트롤 바 (Period Selector)
- **프리셋 기간**: 7일(7D), 1개월(1M, 기본값), 3개월(3M), 6개월(6M), 1년(1Y)
- **사용자 지정 기간**: 시작일(Start Date) ~ 종료일(End Date) 날짜 선택기(Date Picker)
- 기간 변경 시 하단의 모든 금속별 차트가 즉시 동기화되어 재조회

### 2.4 하단 레이아웃: 금속별 세로형 시세 변동 차트 (Bottom Layout)
- **세로 1:1 배치 구조**: 사용자의 요구사항에 맞추어 각 금속 차트가 위에서 아래로 순차 배치
  1. **금 (Gold / XAU)** 시세 변동 추이 차트
  2. **은 (Silver / XAG)** 시세 변동 추이 차트
  3. **구리 (Copper / XCU)** 시세 변동 추이 차트
  4. **플래티넘 (Platinum / XPT)** 시세 변동 추이 차트
- **차트별 세부 구성**:
  - 패널 헤더: 해당 기간 내 **최고가**, **최저가**, **기간 총 변동률(%)** 요약 필(Pill)
  - 차트 그래픽: 부드러운 스플라인 곡선(Bezier tension: 0.35), 금속별 시그니처 그라디언트 에어리어 채우기
  - 마우스오버 툴팁: 정확한 날짜, 통화/단위별 시세, 변동 정보 실시간 안내

## 🚀 3. 실행 방법 (How to Run)

본 프로젝트는 순수 웹 표준(HTML5, Vanilla CSS, Vanilla JS)으로 제작되어 별도의 복잡한 빌드 과정 없이 즉시 실행할 수 있습니다.

### 방법 1. 브라우저로 직접 열기
`index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge) 등의 모던 브라우저에서 바로 열 수 있습니다.

### 방법 2. 로컬 웹 서버 실행 (권장)
Python이 설치되어 있으므로 터미널에서 아래 명령어로 가벼운 로컬 서버를 구동할 수 있습니다.
```bash
# 프로젝트 폴더 내에서 실행
python -m http.server 8000
```
브라우저에서 `http://localhost:8000` 접속

## 🔑 4. MetalpriceAPI 연동 안내

1. [https://metalpriceapi.com](https://metalpriceapi.com)에서 무료 계정 가입 후 API Key를 발급받습니다.
2. 웹 앱 우측 상단의 **[API 설정]** 버튼을 클릭합니다.
3. 발급받은 API Key를 입력하고 **[저장]**을 누르면 실시간 실제 시세 모드로 즉시 전환됩니다.
4. API Key가 없는 상태에서도 **데모 모드**가 내장되어 있어 모든 UI와 차트 인터랙션을 온전히 테스트할 수 있습니다.
